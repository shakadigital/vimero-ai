# Architecture

## Overview
VIMERO follows a tiered architecture leveraging Next.js App Router and Supabase.

## Flow
USER -> NEXT.JS UI -> APPLICATION SERVICE -> DOMAIN SERVICE -> AI ROUTER / PROVIDER ADAPTER -> EXTERNAL PROVIDER

## Status
- Core framework: IMPLEMENTED (Next.js)
- UI: PLANNED (Tailwind, shadcn/ui)
- Backend: IMPLEMENTED (Supabase)

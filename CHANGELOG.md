# Changelog

All notable changes to the VIMERO project will be documented in this file.

## [Phase 14-15] - 2026-09-10
### Added
- **Global UI Standardization**: Introduced `PageContainer` with ambient glow background to unify the look and feel across all dashboard pages (Dashboard Utama, Content Factory, Bank Ide, Kalender Konten, Creative Studio, Target & Goals, Produk & Layanan).
- **Kalender Konten (Scheduler)**: Added a 2-column Kanban-style layout for queuing and scheduling contents.
- **Smart Highlighter**: Added automated highlight mechanism during AI Critic review to pinpoint problematic sentences.

### Changed
- **Content Factory UI**: Refactored the layout to remove the left sidebar (Bank Ide), moving it to its own page (`/pillars`), providing a wider workspace.
- **Calendar Card**: Updated the design to hide the content preview (Hook and Body) by default, using an expandable accordion to keep the queue clean.

## [Phase 12-13] - 2026-09-09
### Added
- **AI Critic & Automated Workflow**: Implemented an automated threshold (score >= 85) for auto-approving content generated by Groq.
- **Manual Revision Feature**: Added the capability to manually override AI drafts before pushing them to the calendar.

## [Phase 9-11] - 2026-09-09
### Added
- **Idea Bank (Bank Ide)**: A repository for content pillars and specific ideas to generate drafts from.
- **Studio Video & Audio**: Integration with TTS and Image-to-Video capabilities (using ElevenLabs/Stable Diffusion concepts).

## [Phase 1-8] - 2026-09-08
### Added
- Setup Next.js 15, TailwindCSS, Shadcn UI.
- Supabase Authentication and RBAC schemas.
- Foundational layouts (Sidebar, KPI Cards).
- Multi-tenant architecture (Business Context).
